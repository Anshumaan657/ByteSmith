# Real-repository evaluation portfolio

This directory is the auditable handoff for Phase 9 repository evidence. Replace
each placeholder only after an owner or maintainer has authorized evaluation.
Record immutable 40-character revisions, the manifest digest, the reviewer,
usefulness, discrepancies, and observations. Never manufacture results.

The portfolio intentionally remains `pending` until five real repositories have
been evaluated. `pnpm validate:spec` validates its shape and requires exactly
one entry for every target profile. The final release audit distinguishes this
external evidence gate from the completed automated engineering gates.

Minimize each material discrepancy into a ChangeBench case when licensing and
confidentiality permit. Otherwise record a non-sensitive description and keep
the underlying evidence with the consenting repository owner.
