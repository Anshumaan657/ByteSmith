# Phase 9D review checklist — distribution and operations

- [x] Local installation is reproducible from an immutable release tag.
- [x] CLI and GitHub Action setup are documented separately.
- [x] Troubleshooting covers Git history, dirty trees, configuration, cache,
  permissions, stale revisions, and incomplete analysis.
- [x] Supported TypeScript, JavaScript, OpenAPI, consumer, and test patterns are explicit.
- [x] Known limitations explain every intentionally unsupported MVP capability.
- [x] The release process covers frozen install, full checks, bundle parity,
  release evidence, immutable tags, and post-release verification.
- [x] Internal packages are not misrepresented as independently published npm packages.
