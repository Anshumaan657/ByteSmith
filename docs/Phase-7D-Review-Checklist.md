# Phase 7D review checklist — analyze, inspect, verify, and benchmark

## Delivered

- [x] `analyze` runs one explicit base/head comparison through the shared engine.
- [x] `contracts` and `test-plan` project focused views from an explicit manifest.
- [x] `verify-impact` validates schema, semantics, digest, repository, commits, and current head.
- [x] `benchmark` runs selected or complete ChangeBench fixtures in temporary Git repositories.
- [x] Benchmark gates cover direct-consumer precision, test recall, determinism, and crash rate.

## Verification

- [x] Focused reports include changed contracts, consumers, commands, and reasons.
- [x] Stale repository heads and corrupted manifests are rejected.
- [x] Selected-case and repeated benchmark orchestration is deterministic.
