# Changelog

## Verify 0.1.0 — release candidate

ByteSmith Verify compares exact Git revisions in TypeScript, JavaScript, and
OpenAPI repositories. It reports contract changes, affected consumers,
recommended Jest/Vitest tests, test gaps, unknowns, and revision-bound evidence
through an offline CLI and advisory GitHub Action.

This is not yet a published release. The final tag requires a passing automated
release audit, five completed real-repository evaluations, and five independent
developer usability evaluations. Unsupported or dynamic behavior remains an
explicit unknown rather than a guessed result.
